**Minesweeper Project**

Allows the user to play minesweeper.

## Installation

All you need is a proper IDE to run the game.

## Usage

First window requests user to input the grid size and number of bombs, pressing the begin button will input these values and tailor a minesweeper game based on these values.   

Second window opens upon pressing begin which allows the user to play minesweeper, finding all bombs or clicking a bomb tile will end the game and open a third window.  

Third window prompts the user on if they wish to restart or close the program with two buttons.
